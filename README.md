- Uses map-based visualization for railway planning.
- Integrates an optimization workflow for maintenance block allocation.

**Stack:** Python, FastAPI, React, TypeScript, Leaflet, Google OR-Tools.

### 03. Retail Predictive Analytics
**Next-60-Day Customer Churn Prediction**

An end-to-end predictive analytics project built using R to identify customers at risk of not making another purchase within the next 60 days.

- Uses the Olist Brazilian E-Commerce dataset.
- Implements data cleaning, exploratory analysis and temporal feature engineering.
- Develops and evaluates machine learning models.
- Includes explainability and customer churn analysis.

**Stack:** R, Machine Learning, Data Analysis, Predictive Modeling, ggplot2.

[View Repository](https://github.com/debosmita-12/Retail-Predictive-Analytics)
